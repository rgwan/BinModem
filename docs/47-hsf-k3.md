**一句话**：k=3 的半格不是远端发的，是**我们自己的判决反馈段**造的（同一前向、砍掉反馈就消失）；

旋转、对 Agere 是错的，所以**默认关**（与 `V92_PAIR_OFFSET` 同性质）。

## 1. 仪器：`V92_B1U_LINE`（每相位的表第一次有正确的相位）

`docs/22` 的教训：一张逐位置的表，相位错一天就等于没测。`V92DFE_TRACE` 把电平标成它**下一个**
符号（`docs/39 §2`），本文不用它。新的 `V92_B1U_LINE` 与 `V92_B1U_LEVELS` **同一调用点、
同一 `self.now`**，多写两列：

```
now raw line forward value mode
```

* `line` = `Symbol::line`：均衡器**被喂进来的那个样本**，任何 tap 都还没作用；
* `forward` = `Symbol::forward`：`self.forward` 抽头对历史的输出，**没有一项来自我们的判决**
  （反馈段的输入是 `self.decided`，也就是本机自己的判决）。

两个字段只有 `V92_B1U_LINE` 设了才写，数据通路一个都不读。`V92_K3` 关掉时三件产物与
`34526d7` **逐字节相同**（§5.3）。

口径与 `docs/39 §5` 一致：残差 = `|level|/G − 最近的奇整数`，单位是半格（一个电平 = 2，
`G = 0.108465229`），k 取解码器自己的符号计数 `n % 4`。窗口 = `score` 段 361 个符号。
两个臂的 k 相位按 `docs/46` 的类模型对齐（HSF shift 0、Agere shift 1；Agere 四位置本来就平，
相位不影响它的任何结论）。

## 2. 归属：半格在我们自己的反馈段里

**两条基线先复现**（`docs/39 §1` 四个数逐项相同）：Agere `ident` 边界 **111432**、
B1u **563 / 450 of 576**、**2063 字节**；HSF `20261024-063632-a41c-off-d1` 边界 **108734**、
**384 / 357 of 576**、**0 字节**。

| 流 | Agere k=0..3 | HSF k=0..3 |
|---|---|---|
| `level`（解码器被喂的） | 0.117 / 0.101 / 0.120 / 0.095 | 0.379 / 0.108 / 0.126 / **0.526** |
| `forward`（无判决） | 0.517 / 0.518 / 0.531 / 0.510 | 0.549 / 0.528 / 0.507 / **0.528** |
| `V92_EQ=linear`（128 抽头、无反馈） | 0.466 / 0.457 / 0.470 / 0.467 | 0.538 / 0.537 / 0.525 / 0.553 |
| **`V92_EQ=47x0`（47 抽头、反馈全零）** | — | **0.506 / 0.475 / 0.479 / 0.486** |

三行读数，一条一条说：

1. **线上没有它**。前向段的 HSF k=3 是 0.528，和 k=1 的 0.528 一模一样；四个位置的均值是
   −0.111 / +0.092 / −0.071 / −0.109，标准误 0.06。远端送来的电平里**没有**位置相关的位移。
2. **它只出现在相加之后**。`level = forward + 反馈段`，反馈段的输入是本机自己的判决：
   `0.379/0.108/0.126/0.526` 与 `0.549/0.528/0.507/0.528` 之差就是反馈段那一份。
3. **砍掉反馈段它就没了**。`47x0` 保留同一套 47 个前向抽头，只把反馈段清零：k=3 上那个
   `3.910 ± 0.056` 的簇从 **45/90 掉到 1/90**，四个位置回到一条线（0.506/0.475/0.479/0.486）。
   这是因果，不是相关。

顺带钉住两个**不是**它的东西：

* **不是 12 符号帧**：一帧里三个 k=3 槽读 +0.367 / +0.429 / +0.410（k=0：−0.294 / −0.234 /
  −0.080），差别在噪声内 ⇒ 它是 **mod 4** 的 trellis 位置效应。
* **不是小数延迟**：小数延迟会**同时**位移四个位置。逐位置残差对自身斜率的回归给出
  k=0..2 **+0.059 / +0.045 / +0.063**（一个小的公共项）、k=3 **−0.159**（符号相反、幅度 2.5 倍），
  而控制位置 k=1、k=2 均值 −0.021 / −0.028，就在栅格上。也**不是幅度**：Agere 的 k=3 幅度最大
  而残差最小（`docs/46 §4`）。

**形状是逐符号、单边、且带簇的**：k=3 上 45/90 个符号全部为**负**，`|level|/G = 3.910 ± 0.056`
（正号侧一个都没有）；k=0 是负侧 −0.346、正侧 +0.219（符号不对称，`docs/39 §5` 的 +0.314/−0.326
是同一件事）。落在 3.91 的这批符号，其 `forward` 值散布在 ±5 之间而 `level` 几乎恒定 ——
**值被钉在一个常数上**，这是误差传播（反馈段首抽头 HSF **+0.63**、次抽头 +0.15；Agere 首抽头
**−0.11**），越过了 `receiver.rs` 自己记的那个 0.5「一个错判决诱发下一个」的界。

⇒ **归属判定：接收侧、我们的，位置在判决反馈段。** 线上是干净的，所以这不是对端或信道的缺陷，
也不是 `docs/44` 关掉的那几条（软判决、判决阈值）能碰的东西。

## 3. 类级拟合：Agere 是零修正控制，而且它真的是零

工具：`crates/datapump/examples/v92_b1u_class.rs`（从 `b1u-class-model` 移植，只用
`docs/46` 的前向模型：`v32::Scrambler` + `v92::modulus::Encoder`，**无 Viterbi、无均衡器**）。
新增 `--fit`：逐位置搜索 **电平偏移 δ**（半步长的网格 ±1.5、步长 0.05）、**增益 γ**（全局，
0.90..1.10、步长 0.005）与**类旋转 d**（mod 8），目标是类一致数最大；平局先用「δ 更小」，
再用「到 `a(eta)` 格的平均距离更小」——后者是必要的，见下。

**Agere `ident`（模型取补，即 8.7.1 那个极性）**

```
fitted on 361 symbols: gamma 1.000, model complemented, 360 classes
  k   today  offset only  rotation only  both   offset  rotation  (distance)
  0     90           90             90     90   -0.050         2  (lattice 0.100)
  1     90           90             90     90   +0.050         0  (lattice 0.115)
  2     90           90             90     90   -0.050         2  (lattice 0.089)
  3     90           90             90     90   +0.000         0  (lattice 0.117)
```

**四个位置的修正都在 ±0.05 半格以内（半个百分点的电平步），γ = 1.000，旋转恰好是
`(2,0,2,0)`（＝`PAIR_FIRST_INDEX_OFFSET` 今天施加的那个），类 360/360。控制通过。**

**HSF**

```
fitted on 361 symbols: gamma 1.000, model not complemented, 324 classes
  k   today  offset only  rotation only  both   offset  rotation  (distance)
  0      0            0             90     90   +0.200         6  (lattice 0.323)
  1      0            0             90     90   +0.100         6  (lattice 0.084)
  2      0            0             90     90   +0.100         6  (lattice 0.098)
  3     11           10             44     54   +0.900         7  (lattice 0.482)
```

两点必须写明：

1. **旋转就是 `docs/46` 预测的那个**：k=0,1,2 是 **6**，k=3 是 **7**（k=3 的类要折半，所以索引
   −2 在类上是 −1）。
2. **k=3 的类一致数对偏移是一个平台**。δ 从 +0.2 到 +0.9，k=3 都是 **54/90**：格距是 2 个半格，
   一格以内的任何偏移都不改「最近奇点」是谁，**类看不见半格**。所以「类一致」这个目标本身
   分辨不出位移的大小；本文用「到格的平均距离」在平台内落点，它选 **+0.9**——也正是那个簇
   的位移（3.910 − 0.9 ≈ 3.0，一个真格点）。这一步是**在平台内选点**，不是绕过平台。

## 4. 三件东西各自的价值（都在同一个 HSF 抓包上）

类级解码（`--decode`：观测类 → 6.4.1 逆 → GPA，**无 Viterbi、无均衡器**，`docs/46 §5` 的口径）：

| 配置 | 类一致（360） | k=3 | 类级解码 ones（1080） |
|---|---|---|---|
| 今天 `(2,0,2,0)`、无电平修正 | 11 = 3.1 % | 11/90 | 753 = 69.7 %（复现 `docs/46`） |
| 旋转 `(6,6,6,6)`（`docs/46 §7`） | — | — | 480 = 44.4 %（复现） |
| 旋转 `(6,6,6,7)` | 314 = 87.2 % | 44/90 | 493 = 45.6 % |
| 只有拟合的电平修正（无旋转） | 11 | 11/90 | — |
| **旋转 + 拟合的电平修正** | **324 = 90.0 %** | **54/90** | **889 = 82.3 %** |

k=3 的类从 **44/90 抬到 54/90**：可用性提高了，但**没有变成 100 %**——因为那个簇只覆盖
45/90 个符号，一个标量挪得动簇，同时也把另外 45 个推离格心（它们仍在同一类里，但余量变小）。
所以 k=3 的类**仍然不是 100 %**，这是本文的老实话。

HSF 那一行的 17 字节不是超时、不是伪造的 CONNECT：日志里是
`B1u confirmed at 576 bits ... 76.0 % ones` → `Ed` → `B1d at 56000` →
`error control: phase "connected", V.42 "V.42, FCS-16"` → `17 bytes to the DTE`，
与 Agere 基线走的是同一串阶段。**判据（B1u ≥ 432/576 且真连接带字节）通过。**

### 5.2 开关是什么

`V92_K3`，默认关，两张表：

```
V92_K3=levels=0.2,0.1,0.1,0.9;rot=6,6,6,7
```

* `levels` = 逐位置电平偏移，单位半格，在 `Decoder::feed` 里**减在 `level / gain` 之后**、
  B1u 第一个符号起生效（`self.n % 4` 取位置）；
* `rot` = 远端类旋转，与 `v92_b1u_class --offset` 同一约定；实现上只施加它与
  `index_to_ki` 已经施加的 `(2,0,2,0)` **之差**，所以默认路径一行不差。
* 关掉 / 解析失败 = 完全无修正。

### 5.3 关掉时逐位相同（证明）

同一份代码的两个树：`~/bm-k3-base`（`34526d7`）与 `~/bm-k3`（本文），两臂各跑一次，
取三件产物（**DTE、`V92_B1U_TRACE`、`V92_ETA_TRACE`**）的 sha256：

```
== base (34526d7) ==                        == new (V92_K3 未设) ==
agere dte 852ed56b…  b1u 3fb36b0c…  eta 09474202…   ← 逐项相同
hsf   dte e3b0c442…  b1u (无)       eta a0bc9f9d…   ← 逐项相同
```

`e3b0c442…` 是空 DTE 的 sha256：HSF 本来就连不上，两个树一样连不上。

## 6. 代价

* **端到端**：同一抓包（`ident.raw`，294 251 个上行符号）四次，开关关 1893/1943/1913/1902 ms、
  开 1894/1923/1908/1935 ms（表内为同样的表、`rot=2,0,2,0`，即行为不变）。差 **2.2 ms / 294 k
  符号 ≈ 0.008 ns/符号**，**在跑间抖动（±20 ms）以下**——这个量在整通呼叫里测不出来。
* **微基准**（`v92_b1u_class --cost`，`black_box` 住，取三轮）：电平表 **2.6 ns/符号**、
  旋转 **1.6 ns/符号**，是**上限**（含 `black_box` 开销）。
* 稳态路径上新增的**只有**：一次 `OnceLock` 读、一次数组下标、一次浮点减；以及一次下标、
  一次整数加、一次 `rem_euclid`。**没有每符号的估计器、没有滤波器、没有新状态。**

## 7. 为什么不翻默认，以及下一步

1. **它对 Agere 是错的**：同一张表把 Agere 的 B1u 从 563 打到 323、字节从 2063 打到 0，因为表里
   带的是 **HSF 的类旋转**，而旋转是每个远端自己的约定（`docs/39 §6`）。按「每一条判据都净胜才
   翻」的约定，**留默认关**：它与 `V92_PAIR_OFFSET` 同性质，是按远端选的旋钮，不是常数。
2. **k=3 的类仍然是 54/90**，不是 100 %。真正的病根在 §2：**反馈段首抽头 +0.63**。
   修它的正路不是逐位置标量，而是让反馈段不要越过 0.5（`receiver.rs` 自己的界）——本文只把
   「砍掉反馈段就干净」（47x0）这个因果量出来，**没有**改拟合的 ridge，因为那属于「调参」，
   本任务没有授权，也没有 Agere 那侧的对照跑过。
3. **要复活的东西**：`docs/46` 的工具（`--fit` / `--levels` / `--cost`）留在这里；
   `V92_B1U_LINE` 留在这里。它们都是关着的、默认不写盘。

**测试基线**：`cargo test -p datapump --lib v92` **185 passed / 6 failed**（6 个全是
`v92::exchange::tests::*`，与 `docs/44 §9` 同）；`cargo test -p ec --lib` **232 / 0**。
`ec` 的 `tests/loopback.rs` 在 `34526d7` 上同样失败（已核），不是本次引入。
